# BIRD-INTERACT

Reference: [2] N. Huo et al., "BIRD-INTERACT: Re-imagining Text-to-SQL Evaluation via Lens of Dynamic Interactions," 2026.

Role: supporting evaluation benchmark.

Runnable baseline suitability: low for the first run. It is cited as an evaluation perspective for interactive Text-to-SQL, while the immediate plan is a small static Spider subset.

Use later for:

- Conversational or interactive Text-to-SQL settings.
- Evaluating whether logging works across multiple user-system turns.
- Comparing static EX/EM against interaction-aware metrics.
