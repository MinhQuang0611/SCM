# Dr.Spider

Reference: [13] S. Chang et al., "Dr.Spider: A Diagnostic Evaluation Benchmark towards Text-to-SQL Robustness," 2022.

Role: diagnostic robustness benchmark.

Runnable baseline suitability: supporting, not an end-to-end model baseline.

Why it is relevant: the source paper cites Dr.Spider's perturbation types as robustness-oriented evaluation. It can guide perturbation design and robustness slices for baseline comparison.

Use later for:

- Robustness perturbation subset construction.
- Stress testing schema-linking and intent paraphrase failures.
- Comparing failure attribution quality across perturbed examples.
